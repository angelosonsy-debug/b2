# B2 Tracker — تطبيق أندرويد

تطبيق أندرويد صغير بيشغّل خطة الـ 84 يوم (`app/src/main/assets/index.html`) جوه WebView،
وبيضيف اللي المتصفح ما يقدرش يعمله:

- **افتح ChatGPT بالبرومبت** → بيبعت البرومبت لتطبيق ChatGPT. لو التطبيق مش متاح بيفتح قايمة مشاركة. لو الاتنين فشلوا بتشوف رسالة الفشل الحقيقية.
- **افتح تطبيق حصيلتي** → أول مرة بيظهرلك قايمة بالتطبيقات المثبتة (مبحوث فيها عن "حصيل" تلقائياً)، اختار حصيلتي مرة واحدة وبيتحفظ. مفيش حاجة تكتبها يدوي ومفيش deep link مطلوب.
- **Backup** → بيطلع قايمة المشاركة بملف `.json`. **استيراد** → بيفتح منتقي الملفات، وبيتحقق من الملف قبل ما يستبدل بياناتك (وبياخد نسخة أمان من بياناتك الحالية الأول).
- روابط YouTube بتفتح في تطبيق YouTube.
- البيانات جوه التطبيق (localStorage). لو الحفظ فشل بيظهر شريط أحمر بيقولك خد Backup.

كل زرار بيرجّع **نتيجة حقيقية** من أندرويد: لو `startActivity` فشل بتشوف السبب، مش "✓" وهمية.

## البناء على GitHub

1. اعمل repository جديد وارفع محتويات الفولدر كلها **ومعاها `.github`** (على Mac: Cmd+Shift+. لإظهار الفولدرات المخفية. أو Add file ← Create new file واكتب `.github/workflows/android.yml`).
2. تبويب **Actions** ← **Android CI** ← **Run workflow**.
3. الخطوات: اختبارات الوحدة ← بناء الـ APK ← رفع الـ APK ← التحقق إن React جوه الـ APK.
4. نزّل الـ Artifact `b2-tracker-debug-apk` وثبّت `app-debug.apk`.
5. (اختياري) نزّل الـ Artifact `gradle-wrapper-files` وارفعه للـ repo لو عايز `./gradlew`.

لو أي خطوة فشلت: نزّل `test-reports` أو انسخ سطور الخطأ من صفحة الـ run.

## أوفلاين

بيتنزّل React وقت البناء ويتحط جوه الـ APK (`assets/vendor/`)، فالتطبيق بيشتغل من غير إنترنت.
الخط (Tajawal) بيتحمّل من النت لو متاح، ولو لأ بيستخدم خط النظام. آخر خطوة في الـ workflow بتفشل لو React ما اتحطش في الـ APK.

## تشخيص المشاكل

- نسخة الـ debug بتسمح بالـ debugging من كروم على الكمبيوتر: وصّل الموبايل ← `chrome://inspect` ← افتح التطبيق.
- أخطاء JavaScript بتظهر في شريط أحمر أسفل الشاشة، وأخطاء التحميل في `adb logcat -s B2Tracker`.
- لو طلع Permission مش مطلوب: مفيش — التطبيق ما بيطلبش غير INTERNET، والباقي (نسخ، مشاركة، فتح تطبيق) مش بيحتاج صلاحيات.

## اختياري

`gradle.properties` فيه `hasilteePackage` كقيمة افتراضية لحصيلتي. مش لازم تغيّره لأن القايمة جوه التطبيق بتحدد الـ package الحقيقي.
